## Bridge v1.2.1 — Settings Refresh

### Improved
- Reorganized settings into compact, consistently spaced cards.
- Removed favorite/pin buttons from Settings.
- Replaced native blue checkboxes with rounded, palette-colored controls.
- Restyled dropdowns, palette selection and action buttons.
- Settings search now hides complete rows and empty groups.
- Added an empty-search state and localized the search placeholder.
- Preserved keyboard focus indicators and reduced-motion support.

### Validation
Checked checkbox appearance, saved values, settings search and removal of pin controls in the desktop WebView.
